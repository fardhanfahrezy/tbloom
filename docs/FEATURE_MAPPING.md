# Pemetaan Fitur End-to-End (Feature Mapping) — TBloom Cake

Dokumen ini memetakan setiap fitur di **TBloom Cake (`tbloom`)** secara menyeluruh mulai dari ID Fitur, Aktor, Status Requirement, Status Implementasi Aktual di Repository, hingga Route, Controller/Service Backend, Tabel Database, dan Komponen React Frontend.

> **Penting bagi AI Agent:** Jangan pernah menganggap fitur berstatus **`Planned`** sudah ada di dalam kode. Selalu periksa kolom **Status Implementasi** sebelum menulis kode.
