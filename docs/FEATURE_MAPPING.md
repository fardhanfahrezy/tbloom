# Pemetaan Fitur End-to-End (Feature Mapping) — TBloom Cake

Dokumen ini memetakan seluruh fitur di **TBloom Cake (`tbloom`)** mulai dari ID Fitur, Aktor, Status Implementasi Aktual di Repository, hingga Route, Controller/Service Backend, Tabel Database, dan Komponen React Frontend.

> Seluruh fitur inti **Fase 1, Fase 2, dan Fase 3** berstatus **`FACT - Implemented`** di repository.
